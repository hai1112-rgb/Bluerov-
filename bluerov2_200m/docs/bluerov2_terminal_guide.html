BlueROV2 200 m Terminal Guide

This page collects the main terminal workflows for the ROS 2 Jazzy BlueROV2 simulation workspace: build, Gazebo, RViz, autonomous navigation, teleoperation, disturbance control, and quick topic checks.

Environment Setup

cd /path/to/bluerov2_200m_optimized
source /opt/ros/jazzy/setup.bash
colcon build --packages-select bluerov2_description bluerov2_control bluerov2_gazebo
source install/setup.bash

Common Launch Commands

The repository uses standard ROS 2 launch and run commands directly; no additional helper script is required.

Direct ROS 2 Launch Commands

ros2 launch bluerov2_gazebo start_enhanced_world.launch.py open_rviz:=false gz_gui:=false
ros2 launch bluerov2_gazebo start_enhanced_world.launch.py open_rviz:=true
ros2 launch bluerov2_gazebo start_enhanced_world.launch.py gz_gui:=true open_rviz:=true
ros2 launch bluerov2_gazebo start_autonomous_demo.launch.py open_rviz:=true
ros2 launch bluerov2_gazebo start_rviz_navigation_demo.launch.py
ros2 launch bluerov2_gazebo start_rviz_navigation_demo.launch.py enable_autopilot:=false

Run Components Individually

ros2 launch bluerov2_control start_thruster_manager.launch.py
ros2 launch bluerov2_control start_sensor_suite.launch.py
ros2 launch bluerov2_control start_localizer.launch.py
ros2 launch bluerov2_control start_autonomous_controller.launch.py
ros2 run bluerov2_control keyboard_wrench_teleop.py --ros-args -r __ns:=/bluerov2
ros2 run bluerov2_control keyboard_disturbance.py

Quick Topic Checks

Command Purpose
ros2 topic echo /bluerov2/pose_gt --once Read one ground-truth pose sample from /bluerov2/pose_gt.
ros2 topic echo /bluerov2/localized_pose --once Read one fused localizer pose sample.
ros2 run tf2_ros tf2_echo world base_link Inspect the world -> base_link transform.
ros2 topic echo /bluerov2/sonar/forward --once Read one forward sonar sample.
ros2 topic echo /bluerov2/sonar/downward --once Read one downward sonar sample.
ros2 topic echo /bluerov2/sensors/magnetometer --once Read one magnetometer sample.

Configuration Files

File Role
src/bluerov2_control/config/TAM.yaml Six-degree-of-freedom thrust allocation matrix.
src/bluerov2_control/config/thruster_manager.yaml Thruster allocation, damping, weights, and diagnostics.
src/bluerov2_control/config/autonomous_controller.yaml Waypoint autopilot gains, limits, click-to-go, and sonar avoidance.
src/bluerov2_control/config/localization.yaml Localizer frames, topics, update rate, and initial pose.
src/bluerov2_control/config/simulator.yaml Vehicle mass, added mass, drag, depth, current, and wave parameters.
src/bluerov2_gazebo/config/disturbances.yaml Deep-water current and thruster fault scenarios.
